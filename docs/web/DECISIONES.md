# Decisiones — web

## 09/10/2026
- Compose Multiplatform para web elegido por el propietario; no React/Capacitor.
- Compilación separada: Kotlin 2.2.21 y Compose 1.9.3 en web; no actualizar versiones Android.
- App → web: lectura directa de fuentes compatibles, sin escrituras de retorno.
- Primer piloto limitado a Filosofía; contenido original, sin modificación académica ni migración de catálogos.
- Persistencia de cuentas, progresión, Firebase, Pro, compras y anuncios quedan fuera del piloto. No simularlos.
- PWA orientada a iPhone/PC; Android conserva acceso web y recibe recomendación opcional de Play.
- No publicación Hosting, GitHub ni Play en esta intervención.
