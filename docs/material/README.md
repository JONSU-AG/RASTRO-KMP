# Material y recursos educativos

Estado más reciente: [correcciones tras las capturas del teléfono](CORRECCIONES_CAPTURAS_2026-11-03.md).

Material abre el catálogo existente de Aprender como consulta: teoría, preguntas o ambas. No concede XP, monedas, estrellas ni modifica vidas o avances. Las respuestas pertenecen a las preguntas de Aprender; no se consulta el banco de Simulador ni sus evaluaciones.

Material conserva el curso de origen. El estudiante elige tema o subtema y lectura vertical continua u horizontal por contenido. Puede ampliar ilustraciones científicas y abrir el modelo 3D disponible. La pizarra es la misma herramienta nativa ya existente.

La revisión administrativa es local: pendiente, revisado o con errores, con una nota de hasta 1000 caracteres. Requiere la identidad administrativa autenticada y verificada. No publica ni edita el catálogo remoto.
