# Pizarra libre

Lienzo Android de RASTRO con trazos de color, selector RGB y grosor de 1 a 100 unidades visuales (dp). Borrador por trazos completos con puntero circular; deshacer y rehacer. Sin cuadrícula.

Guardar exporta PNG mediante el selector de documentos de Android. Compartir exporta PNG temporal mediante FileProvider y el menú del sistema. La imagen contiene solamente el dibujo sobre papel blanco, sin controles ni puntero.

El motor conserva el dibujo al rotar durante la sesión. No hay guardado automático después de cerrar el proceso.

## Borrador — 05/10/2026
Dos opciones: Por trazo elimina líneas completas; Precisión borra únicamente la zona recorrida. Ambas usan el puntero, grosor 1–100 y deshacer/rehacer existentes.
