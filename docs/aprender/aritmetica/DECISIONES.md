# Decisiones

IDs existentes y temario conservados. Problemas completos, condiciones explícitas, cuatro alternativas del mismo ámbito y desarrollo verificable. Gráficos ilustrativos rotulados y separados de los datos particulares de los ejercicios. Sin mezclar contenido de materias o semanas.

02/11/2026: no confundir base porcentual, modelo de capitalización, población con muestra, estimación agrupada con valor exacto o independencia con exclusión mutua. Declarar la convención de cuartiles/percentiles. Mantener fracciones donde se piden y probabilidades entre cero y uno. Los modelos de sucesión y productividad se explicitan; no se infiere una regla única por apariencia. Autoría y SymPy son utilidades locales, no lógica nueva dentro de la app.


- 04/11/2026: la tabla de división usa tres columnas Markdown completas, sin instrucciones de combinación de celdas. Las relaciones entre cocientes y residuos se explican para división inexacta; el caso exacto se trata por separado.
