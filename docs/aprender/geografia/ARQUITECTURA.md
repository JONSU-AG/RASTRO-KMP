# Arquitectura

Los recursos de teoría están bajo shared/src/commonMain/composeResources/files/aprender/geografia y se cargan mediante el sistema existente. Las copias androidUnitTest deben ser equivalentes. Los mapas usan conexiones explícitas del subconjunto Mermaid admitido por AcademicTheoryDocument y AcademicSourceMap. Las comparaciones usan tablas Markdown interpretadas por AcademicTable.

No se modifica el catálogo legacy, el loader, navegación, Firebase ni gamificación.
